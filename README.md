# ModelView — OBJ/MTL/текстуры

Версия для GitHub Pages без Render и без серверной обработки.

Что исправлено:
- светлая тема и светлый фон;
- переключатель освещения без удаления/добавления источников, чтобы не было мерцания;
- обычный режим без синих граней;
- режим «Каркас» использует `EdgesGeometry` и `depthTest`, поэтому скрытые грани не рисуются поверх модели;
- нажатие/клик по конкретному элементу выделяет только этот элемент;
- кнопка «Скрыть» скрывает выбранный элемент;
- «Показать» возвращает все скрытые элементы;
- убраны списки/фильтры выбора деталей и материалов;
- сохранена загрузка OBJ/MTL и ZIP с текстурами;
- пути текстур в ZIP сопоставляются с учетом `/`, `\`, регистра, URL-кодирования и имени файла.

Для GitHub Pages:
1. Загрузите `index.html` и `manifest.webmanifest` в репозиторий.
2. Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
3. Откройте выданную GitHub Pages ссылку на iPhone/Android/Windows.

Рекомендуемая структура ZIP:
Кухня.zip
- Кухня.obj
- Кухня.mtl
- textures/
  - wood.jpg
  - marble.jpg
  - ...

# ModelView v4

Эта версия сделана специально с учётом файла 8_textures.zip.

Причина `Array buffer allocation failed` в предыдущей версии:
OBJ содержит около 52 848 вершин, 105 268 граней и 4 223 material-группы.
Предыдущий код делал `geometry.clone()` для каждой группы, то есть многократно копировал геометрию в память. Это исправлено.

Теперь:
- OBJ/MTL/текстуры загружаются без копирования геометрии для каждой material-группы;
- группы используют общие BufferAttribute/Index;
- выбор происходит по raycast и faceIndex;
- скрывается только выбранная группа, а не вся модель;
- освещение постоянно включено;
- сетка полностью убрана;
- каркас — EdgesGeometry + depthTest;
- текстуры из ZIP подключаются по нормализованному пути и имени;
- цвет текстур переводится в sRGB.

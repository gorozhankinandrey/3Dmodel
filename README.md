# OBJ 3D Viewer v2

Исправленная версия для OBJ/MTL/текстур.

### Что нового
- OBJ разбивается на отдельные геометрические компоненты по связанным полигонам. Это позволяет выбирать и скрывать отдельную физически связанную деталь даже когда экспорт OBJ не содержит `o`/`g` для каждой детали.
- В режиме **Каркас** обычная поверхность почти невидима, а поверх неё строятся внешние/резкие рёбра через `EdgesGeometry` с проверкой глубины. Задние рёбра не должны просвечивать через передние.
- Текстуры ZIP подключаются через Blob URL.
- Светлый фон, постоянное освещение, без сетки и без ползунка освещения.
- Управление OrbitControls подходит для телефона.

### Ограничение
Если две разные детали в OBJ физически соединены общими вершинами/поверхностями, алгоритм может считать их одной деталью. Для 100% корректного выбора деталей лучше экспортировать OBJ с сохранением групп объектов из CAD.

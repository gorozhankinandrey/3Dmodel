# ModelView v5 WORKING

Основа этой версии — предыдущая рабочая версия ModelView OBJ Mobile Pro, которая открывала `8_textures.zip`.

Изменения:
- сохранён прежний рабочий ZIP/OBJ/MTL loader;
- убрана сетка;
- убраны элементы управления сеткой/освещением;
- освещение создаётся один раз и постоянно включено;
- материалам возвращено обычное непрозрачное состояние;
- добавлен выбор конкретного Mesh непосредственно под курсором/пальцем;
- можно скрыть выбранную деталь;
- каркас остаётся с depthTest и не рисует задние рёбра поверх передних;
- не создаются копии геометрии для material-групп.

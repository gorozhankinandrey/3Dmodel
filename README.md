# ModelView v3

Исправления:
- освещение постоянно включено; переключателя освещения больше нет;
- полностью убрана сетка и её переключатель;
- OBJ + MTL + текстуры загружаются через LoadingManager/URLModifier;
- ZIP сохраняет структуру путей текстур;
- режим каркаса использует EdgesGeometry + depthTest, без плоской синей обводки и без принудительной прозрачности всей модели;
- выбор делается raycast по ближайшему Mesh;
- скрытие действует только на выбранный Mesh;
- для OBJ с группами/несколькими материалами группы разбиваются на отдельные элементы, когда это возможно;
- светлая тема.

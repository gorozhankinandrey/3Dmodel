# 3D Model Viewer — GitHub Pages

Полностью статический просмотрщик для **OBJ + MTL + текстур**. Render, Python и сервер не нужны.

## Возможности

- OBJ
- MTL
- JPG / JPEG / PNG / WEBP / GIF / BMP текстуры
- загрузка ZIP на iPhone / Android / Windows
- вращение, масштабирование, панорама
- режим каркаса
- прозрачность 5–100%
- сетка
- виды спереди / сверху / сбоку
- автоповорот

## Структура ZIP

```text
model.zip
├── model.obj
├── model.mtl
└── textures/
    ├── wood.jpg
    ├── stone.jpg
    └── ...
```

Важно: в `.mtl` пути к текстурам должны соответствовать именам файлов. Просмотрщик специально сопоставляет и полный путь, и имя файла, поэтому большинство экспортов из 3D-программ работают без изменений.

## Публикация на GitHub Pages

1. Создайте репозиторий, например `3Dmodel`.
2. Загрузите в корень репозитория:
   - `index.html`
   - `manifest.webmanifest`
   - `README.md`
3. Откройте **Settings → Pages**.
4. В **Build and deployment** выберите:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
5. Нажмите **Save**.
6. Через некоторое время GitHub выдаст адрес вида:

`https://ВАШ_ЛОГИН.github.io/3Dmodel/`

### Важно

Это клиентский просмотрщик: выбранный OBJ/ZIP обрабатывается прямо в браузере. Файл на ваш сервер не загружается.

Для работы Three.js и JSZip используются CDN-ссылки, поэтому при открытии сайта нужен интернет.

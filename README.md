# ModelView v6 Stable

Стабильная версия загрузчика для ZIP с OBJ + MTL + текстурами.

Главное отличие:
- не создаёт копии BufferGeometry;
- каркас не создаётся при загрузке и включается только по кнопке;
- из ZIP создаются Object URL только для OBJ, MTL и изображений;
- постоянное освещение;
- сетка удалена;
- raycast выбирает конкретный Mesh;
- скрывается выбранный Mesh.

Для GitHub Pages достаточно загрузить index.html и manifest.webmanifest.

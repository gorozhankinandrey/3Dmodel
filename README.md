# OBJ 3D Viewer — исправленная версия

Это статический веб-просмотрщик для GitHub Pages / Render / любого обычного HTTPS-хостинга.

## Что исправлено

- ZIP с OBJ + MTL + текстурами открывается прямо в браузере.
- Пути к текстурам из Windows (`\`) нормализуются.
- Текстуры загружаются из ZIP как Blob URL, поэтому им не нужны реальные URL.
- Материалы принудительно остаются непрозрачными в обычном режиме: убрано мерцание/просвечивание.
- Освещение включено постоянно, отдельного ползунка нет.
- Сетка полностью убрана.
- В режиме «Каркас» включён `FrontSide` + depth test/depth write, поэтому задние грани не просвечивают сквозь передние.
- Белый/светлый фон.
- Управление рассчитано и на телефон: OrbitControls с touch-жестами.
- Есть выбор детали кликом/тапом и список частей справа/снизу, где конкретную выбранную часть можно скрыть или вернуть.
- Кнопка «Вписать» автоматически центрирует модель независимо от её размеров.

## Важно про ваш OBJ

В вашем файле `8.obj` нет `o`/`g`-групп — он состоит из 32 материаловых частей. Поэтому OBJLoader видит не каждую мебельную деталь как отдельный объект, а в основном отдельные mesh-части по материалам. Для действительно точного выбора каждой физической детали лучше экспортировать OBJ с группами/объектами или отдельными элементами.

## Публикация

Загрузите содержимое этой папки в GitHub репозиторий и включите GitHub Pages.

Для локального теста нельзя просто открыть `index.html` через `file://` из-за модулей браузера. Запускайте через локальный HTTP-сервер.
